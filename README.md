# 🛍️ OnlineShop - Premium E-Commerce Platform

A sophisticated, luxury-themed e-commerce platform built with **ASP.NET Core MVC**. This project features a unique **"Light Luxury & Ink Wash"** design aesthetic, combining minimalist elegance with modern glassmorphism (frosted glass) effects.

## ✨ Features

- **Exclusive Design Aesthetic:** Features a custom "Ink Wash" (mürekkep yıkama) light theme with deep ink text and frosted glass components.
- **Dynamic Product Showcase:** High-end product landing pages and catalogs.
- **Authentication:** Integrated ASP.NET Core Identity for secure Login and Registration.
- **Shopping Cart:** Seamless cart management.
- **Responsive UI:** Fully responsive design built with custom CSS and Bootstrap 5.
- **Database:** Entity Framework Core with SQLite (easily swappable to SQL Server or PostgreSQL).

## 🎨 Design Philosophy

The UI/UX is built around the **"Light Luxury"** concept:
- **Colors:** Cream/Off-white backgrounds (`#faf9f6`), Deep Ink Black (`#1c1c21`), and Muted Gold accents (`#b08d57`).
- **Glassmorphism:** Elegant use of `backdrop-filter` for transparent, frosted glass navbars and cards.
- **Typography:** Sophisticated fonts with excellent readability and whitespace.

## 🚀 Technologies Used

- **Framework:** .NET 10.0 (ASP.NET Core MVC)
- **Database:** SQLite & Entity Framework Core
- **Authentication:** ASP.NET Core Identity
- **Frontend:** HTML5, CSS3, Bootstrap 5, Bootstrap Icons
- **Architecture:** Repository Pattern (optional/extensible), MVC Pattern

## 🛠️ Getting Started

### Prerequisites
- [.NET 10.0 SDK](https://dotnet.microsoft.com/download) or later
- Visual Studio 2022, Visual Studio Code, or any preferred IDE

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/OnlineShop.git
   cd OnlineShop
   ```

2. **Restore dependencies:**
   ```bash
   dotnet restore
   ```

3. **Apply database migrations:**
   ```bash
   dotnet ef database update
   ```

4. **Run the application:**
   ```bash
   dotnet run
   ```

5. **Open in browser:**
   Navigate to `http://localhost:5050` (or the port specified in your console).
